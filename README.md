# 🎙️ astrbot_plugin_xiaomi_tts

为 [AstrBot](https://github.com/Soulter/AstrBot) 编写的小米 MiMo 大模型音色克隆与 TTS 插件。提供免训练的即时语音合成功能，支持手动指令触发与大模型智能调用。

## ✨ 功能概述

* **即时克隆**：提供 3~10 秒音频直链即可复刻音色。
* **双触发模式**：
  * **指令模式**：通过自定义前缀强制触发语音合成。
  * **智能模式**：注册为 LLM Tool，大模型可根据聊天上下文自主决定是否发送语音。
* **纯云端加载**：支持直接填写 GitHub 文件链接，内部自动转换为 jsDelivr CDN 加速直链，无需本地存放文件和配置内网穿透。
* **防超时切片**：长文本按标点自动分句，流式生成和发送。

## 🛠️ 安装与配置

1. 将 `astrbot_plugin_xiaomi_tts` 目录放入 AstrBot 的 `data/plugins/` 目录下并重启框架。
2. 准备一段符合**克隆黄金标准**的纯净人声干音，放置于插件的 `audio/` 目录下（如 `Aemeath.wav`），或者上传至公开的 GitHub 仓库，并获取该文件的普通浏览器链接。
3. 在 AstrBot WebUI 中配置以下项：
   * **小米 MiMo API Key**：在小米大模型平台申请的密钥。
   * **参考音频直链 (URL)**：填入刚才的 GitHub 链接。
   * **开启 GitHub CDN 镜像加速**：填入 GitHub 链接时保持开启。
   * **手动触发指令**：自定义触发前缀（默认 `/tts`）。
   * **智能语音模式**：是否允许大模型自主调用语音工具。

## 🎧 声音样本（参考音频）格式建议 📌

为了确保小米 MiMo 大模型能够精准提取声纹特征，**极力避免**克隆音色出现**机械杂音、破音、语速失真或左右声道相位偏差**，且为了降低 NAS/服务器的并发读盘压力与大包网络传输延迟，请严格遵守以下音频制式规范：

| 指标项 | 推荐设定值 | 状态 | 为什么这样要求？ |
| :--- | :--- | :--- | :--- |
| **文件格式 (Format)** | **WAV** | 严格推荐 | 无损编码，防止 MP3 等有损压缩导致高频声纹特征丢失。 |
| **采样率 (Sample Rate)** | **16,000 Hz (16kHz)** | 必须满足 | 小米底层模型原生基于 16kHz 训练。过高音质（如 48kHz）会引发网关下采样失真，且导致数据包臃肿。 |
| **声道数 (Channels)** | **单声道 (Mono)** | **绝对强制** | 语音克隆只需单声道。双声道/立体声（Stereo）可能导致合成音频出现诡异的双耳相位差。 |
| **采样深度 (Bit Depth)** | **16-bit** | 标准推荐 | 标准无损位深，平衡了动态范围与内存占用。 |
| **音频时长 (Duration)** | **3 ~ 10 秒** | 最佳区间 | 纯人声过短（低于3秒）声纹不足，过长（超过15秒）容易导致网络传输及 Base64 编码过载。 |

### 💡 快捷转换命令 (FFmpeg)
如果你手头的音频是手机录音或从视频提取的 MP3/AAC 格式，可直接使用以下命令在本地将其一键转换为最完美的格式：
```bash
ffmpeg -i input.mp3 -ar 16000 -ac 1 -b:a 16k output.wav
