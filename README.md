[![Model](https://img.shields.io/badge/Model-小米_MiMo_v2.5-orange.svg)](https://api.xiaomimimo.com)

为 **AstrBot** 机器人框架量身定制的**小米 MiMo 大模型音色克隆与高级语音合成（TTS）插件**。

本插件基于开源大模型与外部通信服务，调用小米 MiMo `mimo-v2.5-tts-voiceclone` 核心 API，仅需数秒的本地声音样本即可在云端完美复刻特定角色（如《鸣潮》中的**爱弥斯**）的音色。针对大模型在调用语音工具时普遍存在的“话痨”、“复述”、“自言自语”等痛点，本插件内置了极其严苛的 **LLM 行为控制链（防废话拦截器）** 与 **自适应情绪调节器**，确保交互即时、干净、自然。

---

## ✨ 核心硬核特性

### 1. 🚀 内存级高并发音频流加载
系统在冷启动时，会一次性扫描并异步读取插件 `audio/` 目录下的所有 `.wav` 和 `.mp3` 格式干音文件。在内存中直接将其转换为标准的 **Base64 DataURL** 缓存。
* **优势**：避免了在群聊高并发、多线程触发语音时频繁进行物理读盘（I/O 操作），极大降低了 NAS/服务器的硬盘压力与响应延迟。

### 2. 🎭 智能情绪总监工具链 (`set_voice_style`)
本插件将情绪调节深度整合为大模型的 **LLM Tool (Function Calling)**。大模型在决定转换语音前，会提前分析即将输出的文本内容及其蕴含的情感色彩，自动调用 `set_voice_style` 工具，实时生成动态情绪 prompt（如：*傲娇的、委屈的、温柔的、撒娇的*）。

### 3. 🛡️ 独创的“情绪降级”防变质算法
在实际测试中，大模型常倾向于生成“超级傲娇”、“极度愤怒”、“无比委屈”等极端副词修饰词，这会导致小米 MiMo API 合成时音频音调严重过载，产生机械杂音、破音或变声。
* **机制**：代码内部通过正则表达式 `re.sub(r'^(超级|极度|无比|万分)', '', style_tag)` 自动拦截并过滤这些过于激昂的副词前缀，实施**情绪降级保护**，确保合成音色始终圆润、还原。

### 4. 🚫 终极防废话拦截器（双向行为锚定）
* **输入端强制注入 (Prompt Injection Control)**：当用户输入匹配到触发词（如 `小爱tts`）时，插件会在消息流末尾强行追加不可见的系统最高规则约束：
  > *“你的所有回复内容（包括前置感叹词、正文以及结束语）必须全部、毫无保留地塞进 speak_tts 的 text 参数中！绝对禁止在聊天框输出任何过渡废话！”*
* **输出端彻底截断 (Event Suppression)**：在 `speak_tts` 工具成功发射语音信号的瞬间，插件会立即执行 `event.stop_event()` 彻底挂起并终止当前消息事件。大模型在底层即便生成了诸如“好的，已经为您转成语音了”之类的尾部总结废话，也会被直接过滤并强行静默，聊天窗只有纯净的语音流。

### 5. 🌐 多层级服务网络兜底
支持**本地+网络双通道缓存**。如果大模型请求的本地音频文件在 `audio/` 目录中意外缺失，系统会自动激活异步网络通道（通过 `aiohttp` 客户端），实时拉取配置的备用网络直链音频，保障服务不断联。

### 6. 🔤 彩蛋文本清洗与发音优化
针对网路社群二次元高频词和特殊符号进行了清洗，防止 TTS 机器读音尴尬：
* 自动将 `ciallo` 替换为 `掐萝`，解决中文大模型直接朗读外来轻小说造词的发音缺陷。
* 自动将网络颜文字和特殊符号进行情感化文字置换（如 `~` $\rightarrow$ `～`，`QAQ`/`TAT` $\rightarrow$ `呜呜`，`www` $\rightarrow$ `哈哈哈`）。

## 📂 插件目录结构

请确保将插件完整解压或放置于 AstrBot 的 `data/plugins/` 路径下，推荐结构如下：

```text
astrbot_plugin_xiaomi_tts/
├── audio/                      # 声音样本存放目录（预加载）
│   ├── Aemeath.wav             # 默认放置的爱弥斯干净人声干音（16kHz，单声道）
│   └── [可自由扩展的其他角色音频.wav/.mp3]
├── main.py                     # 插件主程序（工具注册、前置过滤器、事件全截断控制）
├── tts_service.py              # 小米 MiMo 底层通信协议与 Base64 内存缓存管理
├── _conf_schema.json           # AstrBot WebUI 可视化配置面板元数据
└── metadata.yaml               # 插件身份元信息（版本、作者、依赖）
