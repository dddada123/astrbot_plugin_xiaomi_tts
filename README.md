# 🎙️ astrbot_plugin_xiaomi_tts 

为 [AstrBot](https://github.com/Soulter/AstrBot) 编写的小米 MiMo 大模型音色克隆与 TTS 插件。提供免训练的即时语音合成功能，支持极速的手动指令触发与大模型智能调用。

> **当前版本：v1.7.9**
> (基于最新双轨路由架构，一定程度避免大模型工具幻觉、记忆污染与插件冲突问题。Readme用GemeniPro写的，它总说完美解决，实际上能用，无视它说完美的部分)

## ✨ 核心功能亮点

* ⚡ **极速即时克隆**：只需提供 3~10 秒的纯净干音直链或本地文件，即可完美复刻音色与语气。
* 🛡️ **防误触动态封印**：闲聊时动态植入系统封印指令，降低Token损耗，避免大模型在纯文字聊天时的工具调用幻觉。
* 🤖 **双轨工作模式**：
  * **手动触发**：通过底层物理正则切词，精准无损地唤醒语音，且绝对不会造成大模型长期记忆污染。
  * **智能模式**：注册为 LLM Tool，大模型可根据聊天情绪和上下文，智能打分（0-100分）并自主决定是否发送语音。
* 🤝 **完美的生态兼容**：采用软着陆退出机制，**完美兼容表情包（Meme）、图片等其他拦截类插件**，实现语音+表情包同框发送！
* 📝 **双发与记忆友好**：支持“文字+语音”双轨输出，完美兼容长期记忆插件（如 Memory 插件），避免聊天记录断层。

## 🛠️ 安装与基础配置

1. 将 `astrbot_plugin_xiaomi_tts` 目录放入 AstrBot 的 `data/plugins/` 目录下并重启框架。
2. 准备一段符合**【克隆黄金标准】**的人声干音，放置于插件的 `audio/` 目录下（如 `Aemeath.wav`），或者上传至公开网络获取文件直链。
3. 在 AstrBot WebUI 中配置以下核心项：
   * **小米 MiMo API Key**：在小米大模型平台申请的密钥（按量付费 `sk-` 开头，Token Plan `tp-` 开头）。
   * **服务器集群节点**：如果您是 Token Plan 用户，请务必选择对应的地区集群（否则会报 401 错误）。
   * **手动触发指令前缀**：建议填入 `tts`。

## 🎮 如何使用？

### 1. 手动强制语音 (推荐)
如果你想让大模型立刻发一条语音，请使用：`你的机器人唤醒词 + 触发指令 + 聊天内容`。
* *例如你的机器人叫“小爱”，配置的触发词是“tts”*
* 发送：`小爱tts 今天天气真好啊，快给我讲个笑话！`
* 大模型将瞬间锁定语气并发送语音。

### 2. 智能语音模式 (大模型自主决定)
在 WebUI 中开启【智能语音模式】后，你只需正常和机器人聊天。当大模型判定当前语境非常需要语音互动（如：你发了感叹、撒娇、强烈的情绪起伏），它会给自己打出高分，并自动用语音回复你。

> 💡 **大模型光打字不出声怎么办？（Prompt 排错指南）**
> 如果开启了智能模式，但大模型“死活不发语音”，这通常是因为模型本身比较保守。
> 建议在机器人的 **【人格设定/Prompt】** 中补充一句：
> *『当你收到语音指令，或判断建议发语音时，请积极调用 set_voice_style 和 speak_tts 工具。』*

## 🎧 声音样本（参考音频）格式严格要求 📌

为了确保小米 MiMo 大模型能够精准提取声纹特征，**极力避免**克隆音色出现机械杂音、破音、语速失真或左右声道相位偏差，请**严格遵守**以下音频制式规范：

| 指标项 | 推荐设定值 | 状态 | 为什么这样要求？ |
| :--- | :--- | :--- | :--- |
| **文件格式 (Format)** | **WAV** | 严格推荐 | 无损编码，防止 MP3 等有损压缩导致高频声纹特征丢失。 |
| **采样率 (Sample Rate)** | **16,000 Hz (16kHz)** | **必须满足** | 小米底层模型原生基于 16kHz 训练。过高的采样率会导致下采样失真。 |
| **声道数 (Channels)** | **单声道 (Mono)** | **绝对强制** | 语音克隆只需单声道。双声道/立体声会导致合成音频出现诡异的双耳相位差！ |
| **采样深度 (Bit Depth)** | **16-bit** | 标准推荐 | 标准无损位深，平衡了动态范围与内存占用。 |
| **音频时长 (Duration)** | **3 ~ 10 秒** | 最佳区间 | 纯人声过短（低于3秒）声纹不足，过长（超过15秒）容易导致网络传输过载。 |

### 🌐 懒人格式转换推荐：Convertio
如果你手头的音频是手机录音或从视频提取的 MP3/AAC 格式，不懂怎么调整采样率和单声道，强烈推荐使用免费的在线格式转换工具（手机电脑均可直接打开）：
👉 **[Convertio 在线音频转换 (https://convertio.co/zh/)](https://convertio.co/zh/)**

**转换步骤**：
1. 打开网站，上传你的音频。
2. 目标格式选择 `音频` -> `WAV`。
3. 点击齿轮图标（设置）：
   * **音频通道**：选择 `1 (单声道)`
   * **频率**：选择 `16000 Hz`
4. 点击“转换”并下载，放入 `audio` 文件夹即可完美使用！
